# MAYBE pitch: instructions for Claude (read first)

This repo is the MAYBE hackathon presentation (Macromedia × CODE Hackathon). It's a static site on Vercel with optional serverless functions in `api/`. Two people work on it in parallel:

| Person | Owns | Works on branch |
|---|---|---|
| **Luc** (repo and Vercel owner) | Design: the slides, animations and look | `main` (and `design/*`) |
| **Boris** (partner, backend; GitHub `BorisCarvajal18`) | The voice agents, API keys, `api/` functions, and voice wiring in `assets/voice/` | `voice` (and `voice/*`) |

`main` is production: https://maybe-pitch.vercel.app. Only Luc merges into `main`.

## Golden rules

1. **Never push to `main` directly.** Work on your branch, push, and open a pull request into `main`. Luc reviews and merges.
2. **Never commit secrets.** API keys live in Vercel environment variables (Project → Settings → Environment Variables) and in a local `.env` (gitignored). Use `.env.example` to name the variables without values.
3. **Don't hand-edit generated files.** `index.html` is generated by `node tools/build-deck.mjs` from `src/*.dc.html`, the slide designs exported from Luc's design canvas. To change the look or the copy of a slide, ask Luc; he changes it on the canvas and re-exports. Only touch `src/` or `index.html` if Luc asks.
4. **Stay in your lane** to avoid merge conflicts:
   - Boris: `api/**`, `assets/voice/**`, `.env.example`, `agent-prompt.md`, `LIVE-CALL.md`, plus one-line hooks in `assets/deck.js` (`AGENT_ID`) if needed.
   - Luc: `src/**`, `index.html`, `assets/deck.css`, `assets/live-call.js` (the visuals), `deck/**`, `app/**`.
   - Touching the other person's files? Keep the change minimal and say so in the PR description.
5. **Before every push:** `git fetch origin && git rebase origin/main` (or merge `origin/main` into your branch), run `node tools/build-deck.mjs`, check that the page loads locally, then push.

## How the voice pieces connect to the page (contract; don't break it)

- **Q&A agent (the "Talk to MAYBE" button, all slides):** set `AGENT_ID` in `assets/deck.js`. The page registers ElevenLabs client tools `goToSlide`, `nextSlide`, `prevSlide`, `openScreen` and `getCurrentSlide`. Spec: `agent-prompt.md`.
- **Live-call slide (slide 6: orb, bubbles, Mara):** drive it with `window.MAYBE_CALL`:
  - `connect()` / `disconnect()`
  - `setMode('you'|'agent'|'idle')`
  - `setLevel(0..1)`
  - `addMessage(role, text, {replaceLast})`
  - `clear()`

  Listen for `deck:slidechange` on `document` to start and stop the session. Full spec and example: `LIVE-CALL.md`.
- Put new voice code in `assets/voice/*.js` and load it with one `<script>` tag. Ask Luc to add the tag to the canvas export, or add it in `tools/build-deck.mjs` next to `live-call.js`, so a rebuild doesn't drop it.
- **Server code:** Vercel functions in `api/*.js`, Node 20, CommonJS `module.exports = (req, res) => { … }` (no package.json needed; add one with `"type": "module"` if you prefer ESM). For example, `api/elevenlabs-signed-url.js` reads `process.env.ELEVENLABS_API_KEY` and returns a signed conversation URL, so no key ever reaches the browser.

## Content rules (from the MAYBE brand; don't violate them in prompts or UI copy)

- Never call MAYBE a career test, personality typing or "AI that knows you".
- Companies (DICE, Dr. Lipp, Spotify…) are examples: "mockup only, no partnership implied".
- Every score shows its provenance: Rule-based, Synthetic estimate or AI review. The deal outcome stays separate from the score.
- No invented numbers, prices, user counts or testimonials. Label AI-generated images.
- Agents must say they're AI if asked.
